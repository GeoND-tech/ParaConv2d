# Contributing

Thank you for your interest in this project.

## Pull Requests

This repository is not accepting pull requests.

The repository is published as an educational reference rather than a
community-developed project.

## Bug Reports

If you discover a reproducible bug, please open an issue including:

- operating system
- Python version
- PyTorch version
- compiler version
- CUDA version (if applicable)
- reproduction steps

Bug reports are appreciated.

## Feature Requests

Feature requests, performance improvements, and architectural changes are not
planned for this repository.

The actively developed implementation is maintained separately.

## Questions

Questions about how the implementation works are welcome through GitHub Issues
when they relate to understanding the educational code.
